# Geometri peta provinsi

`indonesia-38-provinces.geojson` disalin dari [denyherianto/indonesia-geojson-topojson-maps-with-38-provinces](https://github.com/denyherianto/indonesia-geojson-topojson-maps-with-38-provinces), commit `80aa4a90ac7eef5136eaa2b551b6aa5d198be27d`. Dataset menyatakan lisensi [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). Atribusi: “Indonesia GeoJSON & TopoJSON Maps (38 Provinces)”.

Sumber menyediakan 38 geometri dan nama provinsi. Empat geometri provinsi hasil pemekaran Papua masih membawa kode lama yang berulang (`91`/`92`); `static/js/province-map.js` memetakan nama fitur tersebut secara eksplisit ke kode Kemendagri `93`–`96`. Nama dan kode lainnya dicocokkan ke `apps/referensi/data/wilayah.csv`.

Repo sumber menyebut data dapat diturunkan dari sumber pihak ketiga, namun tidak menyediakan berkas `SOURCE.md` yang dirujuk. Tinjau ulang provenance upstream sebelum memakai aset ini pada distribusi produksi atau komersial.
